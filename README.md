One word, first thought: **squelch** — an onomatopoeia with a wet,
squelching sound in it, offered with no topic, no explanation, and
no second draft.

`main.py` gates the entry (exactly one word, no spaces or punctuation)
and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, verifying the file
byte-for-byte.
